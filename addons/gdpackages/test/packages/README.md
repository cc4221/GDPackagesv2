# Пример использования GDPackages

Этот пример демонстрирует различные функции фреймворка GDPackages:

## Пакеты

- `hello` - основной пакет с примерами функций
- `world` - пакет, зависящий от hello и демонстрирующий взаимодействие

## Функции фреймворка в действии

### 1. Адаптеры

- Пакеты используют адаптеры для предоставления интерфейса другим пакетам
- Адаптеры обеспечивают слабую связанность между пакетами

### 2. Событийная шина

- Пакеты общаются друг с другом через событийную шину
- Используются события для уведомлений и передачи данных

### 3. Асинхронная загрузка ресурсов

- Пакеты могут асинхронно загружать ресурсы через `PackageThreadedResourceManager`

### 4. Валидация зависимостей

- Пакет world зависит от пакета hello
- Система автоматически загружает зависимости

### 5. Логирование

- Используется централизованная система логирования

## Пример взаимодействия

1. Пакет world загружается после пакета hello (из-за зависимости)
2. Пакеты обмениваются сообщениями через событийную шину
3. Пакеты используют адаптеры для вызова функций друг друга
4. Пакеты инкрементят счетчики друг у друга
5. Демонстрируется асинхронная загрузка ресурсов
